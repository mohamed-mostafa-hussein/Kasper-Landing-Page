# Kasper Landing Page
- A responsive landing page built using HTML5 and CSS3. The project features a modern user interface, responsive layouts, and multiple website sections including services, portfolio, pricing, testimonials, and contact form.

## Features
- Responsive Design
- Modern Landing Page Layout
- Services Section
- Portfolio Gallery
- Pricing Plans
- Testimonials Section
- Contact Form
- Mobile-Friendly Design
- Clean and Organized Code

## Technologies Used
- HTML5
- CSS3
- Font Awesome
- Google Fonts
